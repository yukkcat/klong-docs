## 最重要的三个概念

| 参数 | 示例 | 用户需要知道什么 |
| --- | --- | --- |
| API Base URL | `https://api.klong.lat/v1` | 大多数 OpenAI 兼容客户端都填这个 |
| API Key | `sk-your-api-key` | 从控制台生成，调用时放在请求头 |
| 模型名称 | `gpt-5.4` | 决定这次请求由哪个模型处理 |
| Token | 输入 token / 输出 token | 影响上下文、速度和费用 |
