本页说明小恐龙 API 常见的费用、额度和限流概念。实际价格、可用额度和限流规则以你的账号页面显示为准。

## 计费说明

| 项目 | 示例 |
| --- | --- |
| 计费单位 | 按输入和输出 Token 计费 |
| 扣费时间 | 请求完成后扣除 |
| 余额不足 | 请求会失败，并返回额度相关错误 |
| 流式输出 | 通常按最终实际消耗 Token 计费 |

## 限流说明

| 限制项 | 示例 |
| --- | --- |
| 每分钟请求数 | `60 RPM` |
| 每分钟 Token 数 | `100000 TPM` |
| 最大并发 | 按账号等级或分组配置 |
| 最大上下文 | 以具体模型为准 |

## 使用前建议确认

- 当前账号余额或可用额度是否充足。
- 目标模型是否对你的账号开放。
- 图片、语音、向量等能力是否有单独计费规则。
- 客户端是否开启了流式输出或较大的 `max_tokens`。

<Callout type="tip" title="看不懂扣费时先查用量">
  如果一次请求的消耗和预期不一致，先看 [使用记录](/zh/docs/user-guide/usage-records)，确认模型、输入长度、输出长度和请求时间。
</Callout>
