小恐龙 API 的可用模型以 `GET /v1/models` 返回为准。用户在客户端里填写的模型名，必须和模型列表里的名称完全一致。

## 推荐模型

| 场景 | 推荐模型 | 说明 |
| --- | --- | --- |
| 日常聊天 | `gpt-5.4` | 适合大多数问答、总结、写作和普通对话 |
| 高质量聊天 | `gpt-5.5` / `claude-opus-4-7` | 适合复杂分析、长文档、重要输出 |
| 代码任务 | `gpt-5.5` / `claude-opus-4-7` | 建议在 OpenAI Codex CLI 或 Claude Code 下使用 |
| 低成本快速调用 | `gemini-3.0-flash-low` | 适合批量、低延迟、成本敏感任务 |
| DeepSeek | `deepseek-v4-pro` | 适合中文问答、推理和代码任务 |
| 图像生成 | `gpt-image-2` | 适合文生图和通用图片生成 |
| 高质量图像 | `gpt-image-2-vip` | 适合更高质量图片生成需求 |
| 向量嵌入 | `Qwen/Qwen3-Embedding-8B` | 适合搜索、RAG、相似度匹配 |
| 重排序 | `Qwen/Qwen3-Reranker-8B` | 适合检索结果排序和 RAG 优化 |

<Callout type="tip" title="不知道选哪个">
  普通聊天先用 `gpt-5.4`。质量要求更高时用 `gpt-5.5` 或 `claude-opus-4-7`。代码任务建议放到 Claude Code 或 OpenAI Codex CLI 里跑，Claude Code 优先试 `claude-opus-4-7`，Codex CLI 优先试 `gpt-5.5`。
</Callout>
