这里放真正需要对外展示的客户端教程。用户进来以后，不应该先看到一长串工具名，而是先按自己的使用场景找到入口：终端编程、统一管理、桌面使用，或自托管助手平台。

如果还不知道 Base URL、API Key、模型、token 分别是什么意思，先看 [基础概念](/zh/docs/concepts)。

## 推荐顺序

| 场景 | 推荐入口 | 说明 |
| --- | --- | --- |
| 终端编程，主要使用 Claude Code | [Claude Code](/zh/docs/apps/claude-code) | 最常见的代码助手接入场景 |
| 终端编程，主要使用 OpenAI Codex CLI | [OpenAI Codex CLI](/zh/docs/apps/codex-cli) | 走 OpenAI Responses API |
| 同时管理多个 AI CLI | [CC Switch](/zh/docs/apps/cc-switch) | 统一管理 Claude Code、Codex CLI 等配置 |
| 桌面聊天、写作、翻译 | [Cherry Studio](/zh/docs/apps/cherry-studio) | 最适合普通用户快速上手 |
| 桌面办公、多个 Agent、本地 GUI | [AionUi](/zh/docs/apps/aionui) | 免费开源的桌面办公 Agent |
| 自托管 AI 助手平台 | [OpenClaw](/zh/docs/apps/openclaw) | 适合部署自己的 AI Agent 平台 |

## 通用配置

| 配置项 | 填写值 |
| --- | --- |
| 默认接口地址 | `https://api.klong.lat` |
| OpenAI Base URL | `https://api.klong.lat/v1` |
| API Key | `sk-your-api-key` |
| 推荐聊天模型 | `gpt-5.4`；高质量用 `gpt-5.5` 或 `claude-opus-4-7` |
| 推荐编程模型 | Codex CLI 用 `gpt-5.5`，Claude Code 用 `claude-opus-4-7` |

字段写着“API 地址 / Host / Server URL”时，一般先填 `https://api.klong.lat`。字段写着“OpenAI Base URL / API Base / base_url / baseURL”时，填 `https://api.klong.lat/v1`。

## 每篇教程要回答什么

| 问题 | 说明 |
| --- | --- |
| 适合谁用 | 普通用户、开发者、命令行用户还是自托管用户 |
| 填哪里 | Base URL、API Key、模型名分别在哪个设置项 |
| 怎么验证 | 发一条测试消息，或调用模型列表 |
| 常见错误 | Key 无效、模型不存在、Base URL 填错、接口格式不兼容 |
