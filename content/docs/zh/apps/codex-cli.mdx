Codex CLI 是 OpenAI 的终端编程助手，适合开发者在本地项目里让 AI 读代码、改文件、跑测试。小恐龙 API 已验证支持 `/v1/responses`，所以 Codex CLI 建议走自定义 provider，并把 `wire_api` 设为 `responses`。

<Callout type="info" title="已验证接口">
  Codex CLI 的自定义 provider 需要 Responses API。小恐龙 API 的 `https://api.klong.lat/v1/responses`
  已经可以作为 Codex CLI 接入入口。
</Callout>

<Callout type="tip" title="先区分 Codex 的几种形态">
  OpenAI Codex 有 ChatGPT 里的云端 Codex、IDE 扩展和本地 Codex CLI。本页讲的是能配置自定义 API Provider 的本地 Codex
  CLI；如果你同时用 Claude Code，建议先看 [CC Switch](/zh/docs/apps/cc-switch) 统一管理。
</Callout>

## 需要准备

| 配置项 | 填写值 |
| --- | --- |
| OpenAI Base URL | `https://api.klong.lat/v1` |
| API Key | `sk-your-api-key` |
| 推荐模型 | `gpt-5.5` |
| 配置文件 | `~/.codex/config.toml` |
| 验证方式 | 运行 `codex` 后输入 `/model` 或让它解释当前项目 |

## 安装 Codex CLI

官方推荐通过 npm 或 Homebrew 安装。Windows 用户建议优先使用 WSL2，兼容性更稳；原生 PowerShell 可以尝试，但如果遇到沙箱、权限或命令行工具问题，就切回 WSL2。

### npm

```bash
npm i -g @openai/codex
```

升级到最新版：

```bash
npm i -g @openai/codex@latest
```

### Homebrew

```bash
brew install --cask codex
```

验证安装：

```bash
codex --version
```

## 配置 API Key

### macOS / Linux / WSL

```bash
export KLONG_API_KEY="sk-your-api-key"
```

想长期生效，可以写入 `~/.zshrc` 或 `~/.bashrc`：

```bash
echo 'export KLONG_API_KEY="sk-your-api-key"' >> ~/.zshrc
source ~/.zshrc
```

### Windows PowerShell

```powershell
[Environment]::SetEnvironmentVariable("KLONG_API_KEY", "sk-your-api-key", "User")
```

设置后重新打开 PowerShell。

## 修改配置文件

Codex CLI 的配置文件通常在：

```txt
~/.codex/config.toml
```

写入下面的配置：

```toml
model = "gpt-5.5"
model_provider = "klong"
model_reasoning_effort = "high"

[model_providers.klong]
name = "小恐龙 API"
base_url = "https://api.klong.lat/v1"
env_key = "KLONG_API_KEY"
wire_api = "responses"
```

<Callout type="warn" title="不要把真实 Key 写进配置文件">
  推荐使用 `env_key` 读取环境变量。这样配置文件可以截图、同步或发给别人看，不会把真实 API Key 泄露出去。
</Callout>

## 怎么确认请求走的是小恐龙 API

1. 运行 `codex`，进入任意项目目录。
2. 输入 `/model`，确认选择的是你配置里的 `gpt-5.5`。
3. 让 Codex 执行一个只读任务，比如“总结这个项目目录结构”。
4. 打开小恐龙 API 的使用记录或用量页面，确认出现 Responses API 调用。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 401 | 检查 `KLONG_API_KEY` 是否在当前终端生效 |
| 404 | 检查 `base_url` 是否是 `https://api.klong.lat/v1`，并确认服务支持 `/v1/responses` |
| 仍然请求官方 OpenAI | 检查 `model_provider = "klong"` 是否写在配置文件顶层 |
| 模型不存在 | 换成小恐龙 API 模型列表里的完整模型名 |
| Windows 运行失败 | 优先切到 WSL2 使用；Windows 原生 PowerShell 遇到沙箱或命令兼容问题比较常见 |
