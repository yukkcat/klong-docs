Claude Code 是 Anthropic 官方的终端编程助手，适合在本地项目里读代码、改文件、运行命令、生成提交说明。它和普通聊天客户端不一样：Claude Code 走的是 Anthropic Messages API 兼容接口，不是 OpenAI `chat/completions` 格式。

<Callout type="warn" title="先确认兼容性">
  小恐龙 API 的 OpenAI Chat Completions 和 Responses API 已经可以给常见 OpenAI 兼容客户端使用。Claude Code 还需要服务端支持 Anthropic
  Messages API 兼容路径。接入前请确认你的账号、模型和网关已经开放 Claude 兼容调用。
</Callout>

<Callout type="tip" title="多数开发者优先用 CC Switch">
  如果你还要同时配置 Codex CLI、Gemini CLI，或经常切换多个模型，建议先看 [CC Switch](/zh/docs/apps/cc-switch)。本页是 Claude
  Code 的手动配置教程。
</Callout>

## 安装 Claude Code

Claude Code 官方当前推荐使用 Native Install。旧的 `npm install -g @anthropic-ai/claude-code` 仍可作为备用方式，但新用户优先用下面的安装命令。

### macOS / Linux / WSL

```bash
curl -fsSL https://claude.ai/install.sh | bash
```

如果安装后提示找不到 `claude` 命令，把本地 bin 目录加入 PATH：

```bash
echo 'export PATH="$HOME/.local/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

### Windows PowerShell

```powershell
irm https://claude.ai/install.ps1 | iex
```

### Windows CMD

```cmd
curl -fsSL https://claude.ai/install.cmd -o install.cmd && install.cmd && del install.cmd
```

### Homebrew / WinGet

```bash
brew install --cask claude-code
```

```powershell
winget install Anthropic.ClaudeCode
```

验证安装：

```bash
claude --version
```

## 配置小恐龙 API 接入

Claude Code 连接第三方网关时，关键是两个环境变量：

| 变量 | 作用 |
| --- | --- |
| `ANTHROPIC_BASE_URL` | 把 Claude Code 的请求转发到小恐龙 API |
| `ANTHROPIC_AUTH_TOKEN` | 以 `Authorization: Bearer ...` 的形式发送你的 API Key |
| `ANTHROPIC_MODEL` | 可选，指定本次启动默认模型 |

### macOS / Linux / WSL

```bash
export ANTHROPIC_BASE_URL="https://api.klong.lat"
export ANTHROPIC_AUTH_TOKEN="sk-your-api-key"
export ANTHROPIC_MODEL="claude-opus-4-7"
```

想长期生效，可以写入 `~/.zshrc` 或 `~/.bashrc`：

```bash
cat >> ~/.zshrc <<'EOF'
export ANTHROPIC_BASE_URL="https://api.klong.lat"
export ANTHROPIC_AUTH_TOKEN="sk-your-api-key"
export ANTHROPIC_MODEL="claude-opus-4-7"
EOF
source ~/.zshrc
```

![macOS 配置环境变量](/assets/claude_code/macos_configure.png)

### Windows PowerShell

```powershell
[Environment]::SetEnvironmentVariable("ANTHROPIC_BASE_URL", "https://api.klong.lat", "User")
[Environment]::SetEnvironmentVariable("ANTHROPIC_AUTH_TOKEN", "sk-your-api-key", "User")
[Environment]::SetEnvironmentVariable("ANTHROPIC_MODEL", "claude-opus-4-7", "User")
```

设置后重新打开 PowerShell，让环境变量生效。

![Windows 配置环境变量](/assets/claude_code/windows_configure.png)

## 怎么确认请求走的是小恐龙 API

1. 在终端运行 `claude` 后输入 `/status`，确认当前模型和配置。
2. 问一个简单问题，比如“解释这个项目的目录结构”。
3. 打开小恐龙 API 的使用记录或用量页面，确认刚才产生了请求。
4. 如果没有日志，优先检查环境变量是否在启动 `claude` 的同一个终端里生效。

## 常见问题

| 问题 | 处理方式 |
| --- | --- |
| `claude` 命令找不到 | 重新打开终端，或把 `~/.local/bin`、`%USERPROFILE%\.local\bin` 加入 PATH |
| 401 / 无法鉴权 | 检查 `ANTHROPIC_AUTH_TOKEN` 是否填了自己的小恐龙 API Key |
| 404 | 确认 `ANTHROPIC_BASE_URL` 不要多写 `/v1`，并确认服务端支持 Anthropic 兼容路径 |
| 模型不存在 | 换成小恐龙 API 模型列表里真实存在的 Claude 兼容模型名 |
| 返回格式错误 | 当前网关可能只支持 OpenAI 格式，还没有适配 Anthropic Messages API |
| 不想每次都 export | 把变量写进 shell profile，或用 Claude Code 的 `settings.json` 的 `env` 配置 |
