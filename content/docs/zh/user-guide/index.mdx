用户指南主要写给已经拿到小恐龙 API 账号的人。这里不先讲代码细节，而是说明你在控制台里应该怎么创建令牌、查看价格、检查用量、充值配额，以及怎么把 API 接入聊天应用。

## 适合谁看

| 你想做什么 | 应该看哪里 |
| --- | --- |
| 创建或管理 API Key | [令牌管理](/zh/docs/user-guide/tokens) |
| 知道 API 地址怎么用，先测试一次请求 | [使用 API](/zh/docs/user-guide/api-usage) |
| 把账号接入聊天应用 | [聊天应用集成](/zh/docs/user-guide/chat-apps) |
| 查看不同模型怎么收费 | [定价](/zh/docs/user-guide/pricing) |
| 查每次调用消耗了多少 | [使用记录](/zh/docs/user-guide/usage-records) |
| 充值、兑换码、余额不够 | [配额与充值](/zh/docs/user-guide/quota-billing) |

## 推荐顺序

1. 先看 [令牌管理](/zh/docs/user-guide/tokens)，创建一个专门用于测试的 Key。
2. 再看 [使用 API](/zh/docs/user-guide/api-usage)，用操练场或 curl 验证这个 Key 能正常调用。
3. 如果是给非开发用户使用，继续看 [聊天应用集成](/zh/docs/user-guide/chat-apps)。
4. 开始正式使用前，看一下 [定价](/zh/docs/user-guide/pricing) 和 [配额与充值](/zh/docs/user-guide/quota-billing)。
5. 用了一段时间后，通过 [使用记录](/zh/docs/user-guide/usage-records) 排查费用、失败请求和模型消耗。
