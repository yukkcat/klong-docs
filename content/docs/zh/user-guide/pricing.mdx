定价页用于查看每个模型的计费方式。不同模型的输入、输出价格可能不同，代码模型、长上下文模型、图像模型也可能有额外计费规则。

![定价页全貌](/assets/guide/feature-guide/pricing.png)

## 怎么看价格

| 字段 | 含义 |
| --- | --- |
| 模型名称 | 调用时填写的 `model` 值 |
| 输入价格 | 用户问题、上下文、系统提示词产生的消耗 |
| 输出价格 | 模型回复内容产生的消耗 |
| 分组倍率 | 不同账号或套餐可能有不同折扣或倍率 |

## 输入和输出

一次请求通常分成两部分计费：

1. 输入：你发给模型的内容，包括提示词、历史消息、上下文。
2. 输出：模型生成的回复。

如果你发送很长的上下文，输入会变多。如果让模型生成长文、代码、报告，输出会变多。

## 搜索模型

在定价页顶部搜索模型名称，可以快速找到某个模型的价格。比如搜索 `gpt`、`claude`、`embedding`。

## 使用建议

- 日常聊天优先选择低成本、响应快的模型。
- 写代码、复杂分析、长文档处理再选择能力更强的模型。
- 批量任务先用小样本测试消耗，再扩大规模。
- 不确定价格时，先在操练场跑一次，再到使用记录查看实际扣减。

## 价格以哪里为准

文档只解释计费概念，实际价格以控制台定价页显示为准。如果同一个模型在不同账号、分组或套餐下显示不同，以你当前账号看到的价格为准。
