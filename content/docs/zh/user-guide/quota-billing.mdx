配额可以理解为账号余额或可用额度。调用模型时，系统会根据模型价格、输入输出 token、分组倍率等规则扣减配额。

![充值页面](/assets/guide/feature-guide/topup.png)

## 什么时候会扣配额

| 场景 | 是否消耗 |
| --- | --- |
| 查询模型列表 | 通常不消耗或消耗极少 |
| 发送聊天请求 | 会按输入和输出扣减 |
| 生成长文、代码、报告 | 输出越多，消耗越多 |
| 请求失败 | 视失败阶段而定，通常可在使用记录里查看 |

## 充值方式

具体充值方式以控制台显示为准，常见方式包括在线支付和兑换码。

![选择支付方式](/assets/guide/feature-guide/topup-payment.png)

如果你拿到的是兑换码，可以在充值页找到兑换码区域输入。

![兑换码输入区域](/assets/guide/feature-guide/topup-redeem.png)

## 余额不足怎么办

1. 先确认使用记录里最近的消耗是否正常。
2. 如果是某个令牌异常消耗，先禁用这个令牌。
3. 查看定价页，确认是否调用了更贵的模型。
4. 按控制台提示充值或使用兑换码。
5. 如果余额已经充值但未到账，保留支付记录并联系管理员。

## 邀请和返利

如果平台开启邀请功能，充值页或个人设置页可能会显示邀请码、返利余额等信息。

![邀请码与返利区域](/assets/guide/feature-guide/topup-invite.png)

这类规则以控制台实际显示为准。公开文档只说明入口和概念，不承诺固定返利比例。

## 使用建议

- 给测试令牌设置较小配额，防止误调用。
- 批量任务先用少量数据估算费用。
- 高价模型只给可信令牌开放。
- 定期查看使用记录，发现异常及时停用令牌。
