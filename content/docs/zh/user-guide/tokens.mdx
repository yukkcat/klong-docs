令牌就是你调用小恐龙 API 时使用的 API Key。每个令牌都可以单独设置名称、有效期、可用模型、配额上限和 IP 白名单，适合按用途拆分管理。

![令牌列表页](/assets/guide/feature-guide/token-list.png)

<Callout type="warn" title="请保护好令牌">
  令牌等同于账号调用权限，不要发到群里、不要写进公开仓库，也不要放在前端代码里。文档里的 `sk-your-api-key` 只是示例占位符。
</Callout>

## 什么时候需要新建令牌

| 场景 | 建议 |
| --- | --- |
| 第一次测试 API | 创建一个名为“测试”的令牌，设置较小配额 |
| 给客户端使用 | 每个客户端单独一个令牌，方便停用和排查 |
| 生产环境调用 | 单独创建生产令牌，避免和测试混用 |
| 临时给别人试用 | 设置过期时间和配额上限 |

## 创建令牌

<Steps>
  <Step title="进入令牌页面">
    登录控制台后，进入「令牌」或「令牌管理」页面。
  </Step>
  <Step title="点击创建令牌">
    点击「创建令牌」按钮，填写容易识别的名称，比如“Claude Code 测试”或“Cherry Studio”。
  </Step>
  <Step title="按需设置限制">
    可以限制有效期、最大配额、允许模型、IP 白名单和分组。第一次测试可以先保持默认，只设置名称。
  </Step>
  <Step title="复制完整 Key">
    提交后会显示完整令牌，请立刻复制保存。关闭弹窗后通常无法再次看到完整 Key。
  </Step>
</Steps>

## 常见配置项

| 配置项 | 说明 |
| --- | --- |
| 名称 | 方便你分辨这个 Key 给谁用、在哪里用 |
| 过期时间 | 到期后自动失效，适合临时测试 |
| 剩余配额 | 限制这个令牌最多能消耗多少余额 |
| 无限配额 | 不限制该令牌本身，但仍受账号总余额限制 |
| 模型限制 | 只允许调用指定模型，避免误用昂贵模型 |
| IP 白名单 | 只允许固定服务器或办公网络调用 |
| 分组 | 使用指定分组的模型和价格策略 |

## 编辑和删除

令牌创建后，可以编辑名称、配额、模型限制、IP 白名单等配置。如果令牌泄露或不再使用，直接删除或禁用即可，删除后这个 Key 会立即失效。

## 建议做法

- 测试、生产、不同客户端分别创建不同令牌。
- 给别人试用时设置配额上限和过期时间。
- 发现异常消耗时，先禁用对应令牌，再查看使用记录。
- 不要把同一个令牌到处复制，后面很难排查来源。
