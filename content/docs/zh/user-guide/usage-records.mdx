使用记录用于排查“谁用了 Key、调用了什么模型、消耗了多少、为什么失败”。普通用户通常只能看到自己账号下的调用记录。

![个人日志页](/assets/guide/feature-guide/log-list.png)

## 记录里有什么

| 字段 | 用途 |
| --- | --- |
| 时间 | 判断请求发生在什么时候 |
| 令牌 | 判断是哪一个 Key 发起的请求 |
| 模型 | 判断实际调用了哪个模型 |
| 输入 / 输出 token | 判断上下文和回复长度 |
| 配额消耗 | 判断本次请求扣了多少余额 |
| 状态 | 判断请求成功、失败或被拒绝 |

## 筛选记录

记录多了以后，可以按时间、模型、令牌等条件筛选。

![日志筛选条件展开状态](/assets/guide/feature-guide/log-filter-open.png)

常见筛选方式：

1. 选择时间范围。
2. 输入模型名称关键词。
3. 选择或输入令牌名称。
4. 点击查询，查看过滤后的结果。

![过滤后的日志列表](/assets/guide/feature-guide/log-filtered.png)

## 看每日趋势

数据看板可以查看每天的调用量和配额消耗趋势，适合判断最近是否突然变贵、是否有异常调用。

![个人数据统计图表](/assets/guide/feature-guide/dashboard-chart.png)

## 常见排查

| 问题 | 看哪里 |
| --- | --- |
| 余额消耗很快 | 按模型和令牌筛选，看是否用了高价模型 |
| 某个客户端不能用 | 按令牌筛选，看有没有失败记录 |
| 输出太长导致费用高 | 查看输出 token 是否明显偏高 |
| 怀疑 Key 泄露 | 查看来源、时间和令牌，必要时立即禁用令牌 |
