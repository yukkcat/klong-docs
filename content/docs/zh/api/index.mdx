这里是小恐龙 API 对外调用的 **AI 模型接口**。普通用户和开发者只需要关注模型列表、聊天、Responses、向量、图像、音频等模型能力；账号、令牌、用量和充值说明放在 [用户指南](/zh/docs/user-guide)。

<Callout title="基础地址">
  默认接口地址：`https://api.klong.lat`。OpenAI Base URL：`https://api.klong.lat/v1`。文档里的 `sk-your-api-key`
  是占位符，实际调用时请替换成自己的 API Key。
</Callout>
